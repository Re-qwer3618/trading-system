# 관심종목 후보 스크리닝

`src/screen_candidates.py`를 실행해 그 결과를 그대로 보여주고 설명한다. 직접 규칙을 짜거나
숫자를 새로 계산하지 않는다 — 스크립트 안의 `RULES`가 유일한 근거다.

## 실행

```
run.bat screen --add
```

기본값: 시가총액 상위 300종목 스캔, 상위 10개. 더 넓게 보려면 `--n 500`, 관심종목만 다시 보려면
`--scope watchlist`. `--add`를 빼면 미리보기만(관심종목을 바꾸지 않음) — 사용자가 "미리 보여줘"라고
하지 않는 한 `--add`를 붙여 실제로 추가한다(로컬 DB의 관심종목 태그를 바꾸는 것뿐이라 되돌리기 쉬움).

## 결과를 전달할 때 반드시 포함할 것

1. **기준일** (스크립트가 출력하는 "기준일: YYYY-MM-DD"). 이 프로젝트는 시장 데이터가 장 마감 후
   수집되므로, "오늘"이 아니라 이 기준일 시점의 판단임을 분명히 한다.
2. **각 종목이 어떤 규칙에 걸렸는지** (`hits` 열) — "왜 골랐는지" 없이 종목명만 나열하지 않는다.
3. **이미 관심종목이던 것과 새로 추가된 것**을 구분해서 말한다.
4. **아래 caveat을 항상 붙인다** (매수 권유로 읽히지 않게):
   - 통계적으로 약한 우위다(과거 검증 기준 5거래일 보유 시 평균 초과수익 +0.1~0.3%대, 승률이 50%를 크게 넘지 않음).
   - 관심종목에 넣은 것이지 매수 주문은 아니다. 실제 매수 판단은 `live_trade.py`(전략 신호 + 리스크 관리)가 별도로 한다.
   - 상장폐지 종목이 표본에서 빠져 있어(생존편향) 실제보다 낙관적일 수 있다.
   - 규칙은 특정 기간(2021~2026, 시가총액 상위 종목)에서 검증된 것이라 시장 국면이 바뀌면 안 통할 수 있다.

## 규칙이 오래됐을 때

`src/screen_candidates.py`의 `RULES` 주석에 마지막 검증 날짜가 적혀 있다. 분기(3개월) 이상 지났거나
사용자가 "다시 검증해줘"라고 하면, `run.bat research`(전략 검증 도구, `pages/5_전략_검증.py`와 같은 로직)로
다시 돌려 규칙 탐색(`discover_rules`) 결과를 확인하고, 여전히 검증(학습/뒤 구간 모두 양의 초과수익 + t값)을
통과하는 규칙으로 `RULES`를 갱신한다. 근거 없이 규칙을 새로 지어내지 않는다.

## 하지 말 것

- 이 스킬로 찾은 종목을 곧바로 매수하라고 권하지 않는다.
- `RULES`에 없는 조건(뉴스, 테마, 직감)을 섞어서 고르지 않는다 — 검증되지 않은 추측이 된다.
- 사용자가 특정 종목을 콕 집어 "오를까?"라고 물으면 이 스킬이 아니라 `chart-psychology` 스킬(차트 심리분석)을 쓴다.
