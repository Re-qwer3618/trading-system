# 해석 규칙 모음

사용자의 분석 노트와 차트 메모에서 뽑은 규칙이다. 규칙은 **단독으로 결론 내지 말고**, 시장 흐름·다음날 반응과 교차 확인한다.

## 1. 시장 대비 움직임

| 관찰 | 해석 |
|---|---|
| 시장 폭락에도 시장 대비 버팀 | 폭락에 매수세가 강해질 이유는 없다 → **매도할 사람이 없어서** 버티는 것 |
| 많이 오른 뒤 시장 공포에도 크게 안 빠짐 | 아까워서 파는 사람이 없다 |
| 시장 하락 때 같이 하락, 거래량 없음 | 매수세 위축에 의한 하락 (매도세 증가 아님) |
| 시장 하락 때 꾸준히 흘러내림, 시장 반등에도 못 따라감 | 매수세 관심이 사라진 것 |
| 시장 상승에 못 따라가고 조정 | 더 비싼 가격에 사려는 매수세가 없다 |
| 시장 반등에 빠르게 반등하지만 연속 상승 없음 | 매수세 확신 부족, 시장 변동성에 종속 |
| 버티는데 상승도 못함 | 매수세가 강한 게 아니라 **보유자 자체가 없는 것**. 보유 심리가 강하면 제자리에서라도 버틴다 |
| 이전엔 시장 따라 하락, 이제는 시장 대비 버팀 | 위축될 매수세도, 팔 매도자도 남아있지 않다 → 바닥 형성 신호 후보 |
| 관심 없던 종목이 시장 반등을 따라 오름 | 더 줄어들 매수세가 없다 |

## 2. 하락 원인 판별: 매도세 증가 vs 매수세 위축

- **매도세 증가**라면: 선발 매도세 → 공포·불안 확대 → 후발 매도세가 계속 나와야 한다. 시장이 크게 하락할 때 매수세와 싸우며 거래량이 증가해야 한다.
- 그런데 후발 매도가 멈추고 아래꼬리를 남기거나, 시장 하락일과 겹친다면 → **매수세 위축**에 의한 하락이다.
- 매도세가 없는 상태에서 선발 매도세가 나왔다면 → 매수세가 위축될 "무엇인가"가 나왔다는 것. 이후 흐름을 경계한다.

## 3. 캔들 꼬리

| 캔들 | 해석 |
|---|---|
| 상한가 터치 후 위꼬리 마감 | 상한가에 기대감이 없다, 보유·매수하려는 사람이 없다 |
| 호재에 위꼬리 길게 | 호재에 대한 기대감이 없다. 앞으로 더 큰 호재가 없으면 상승이 어렵다 |
| 선발 매수세 후 위꼬리 | 비싸게 사려는 사람은 있으나 확신이 없어 지키지 못했다 |
| 매물대 돌파 후 위꼬리 **없이** 마감(호재 없는 자력 상승) | 매도자 없는 가격대인데 더 비싸게 사려는 조급한 사람이 없다 → 매수세 약함, 연속 상승 가능성 낮음 |
| 하락 중 아래꼬리 | 불안 매도가 일시적으로 나왔지만 추가 매도세가 없다 |
| 아래꼬리가 짧음 | 불안감에 파는 사람이 많지 않다 |
| 시장은 아래꼬리 상승인데 종목은 시가 낮게 시작해 아래꼬리 없음 | 시장 불안감에 파는 사람이 없다. 상승 마감도 매수세가 아니라 매도자가 없어서 따라 오른 것 |
| 바코드 모습(위아래 꼬리 반복) | 보유자·매수자 모두 확신이 없다 |

## 4. 거래량

- 상승하는데 거래량 감소 + 점점 위꼬리 → 추가 매수 없음, 매수한 사람도 보유하려 하지 않음 → **상승 기대감 소멸**.
- 상승하며 매수는 늘었는데 못 오름 → 추가로 들어올 매수가 없을 가능성이 높다.
- 조금 올랐는데 거래량 급증(매물도 없는 자리) → 주포 탈출 의심.
- 조정 중 평균 거래량 증가 + 하락 → 매수/매도 모두 늘었는데 하락, 경계.
- 급등 후 하락 시 거래량 증가, 이후 조정에선 거래량이 크게 늘지 않음 → 팔 사람은 이미 팔았다. 누가 남았는지 질문한다.
- 신고가 후 강한 거래량과 함께 상승 → 기대 매수 증가, 불안 매도와 전쟁 중.
- 대량 거래 연속 상승했지만 이전 고점 매물대에서 밀림 → 매수 관심은 생겼지만 매도자를 이길 만큼은 아님.
- 매물대를 **작은 거래량으로 돌파** → 매도하는 사람이 없어 작은 매수세에도 쉽게 상승.
- 거래량이 줄며 연속 상승 못함 → 매도자가 없어서 거래량이 줄었을 뿐 매수세도 약하다.

## 5. 매물대와 가격대

- 매물대 = 이전 고점/박스에서 물린 사람들의 가격대. 대량 거래가 나온 가격대가 강한 매물대.
- 본전에 온 보유자는 매도한다 → 매물대 근처에서 상승이 막히는 이유.
- 매물대 돌파 후엔 "앞으로 매도할 사람이 없는 가격대"가 된다.
- 돌파 실패 시 → 매수세가 다시 관심 가질 때까지 하락 가능. 단, 시장이 크게 빠지지 않으면 **매도자 없는 가격**(아래 박스 상단/지지선)까지만 하락할 가능성이 높다.
- 번번이 막히는 가격 = "안 사려는 구간". 이 구간 돌파가 매수 시점 판단의 기준이 된다.

## 6. 호재·이벤트

- 호재 때만 매수세가 관심 → 이후 다시 하락 = 호재 의존 종목.
- 강한 호재(상한가급)인데 거래량이 이전 호재 때와 비슷 → 산 사람이 많은 게 아니라 판 사람이 없어서 오른 것. 지키지 못하면 매수세 약함.
- 호재 다음날 후발 매수세 후 위꼬리 → 사고 싶은 사람은 많으나 확신이 없다. 당장 싸게 파는 사람도 없어 크게 빠지지도 않는다.
- 호재 때도 안 산 매수세가 하락을 기회로 살 가능성은 낮다.
- 권리락·무상증자·감자·배당락 표시를 확인하고 가격 비교 시 수정주가 여부를 감안한다.

## 7. 매매 원칙 (자기반성에서 나온 규칙)

- 일봉 심리분석과 저점 확인을 끝낸 뒤에만 매수 결정한다.
- 매수 시점: 1차 매물대(안 사려는 구간) 돌파 후 **선발대가 연속으로 나오는 시점**, 비중은 작게.
- 장 초반 매수 대신 장 후반까지 매수세 유지를 확인하거나, 다음날 시가가 낮게 시작하지 않으면 매수.
- 시장 변동성이 남아 있고 종목이 시장에 종속적이면, 시장과 함께 하락했을 때를 노린다.
- 단타는 20일 이평선 기준으로 대응.
- 매수 전에 매도 시점(목표·손절)을 확정한다. 본전 매도·손절을 해본 적 없는 "무조건 10~20% 익절"은 맞지 않을 수 있다.
- 개인의 투자 역량에 맞게 매매한다.
