# 분석 보고서 양식

기존 hwp 노트의 `<종목명><분석일자> / <주요사항><저점 : 매물대 : 매수타이밍 :>` 구조를 그대로 옮긴 양식이다.

```markdown
# {종목명} 심리분석

- 분석일: YYYY. MM. DD. (요일)
- 비교 지수: 코스닥 / 코스피
- 차트 기간: YYYY.MM ~ YYYY.MM (일봉)

## 주요사항

| 구분 | 내용 |
|---|---|
| 저점 | ○○,○○○원 대 (근거: 시장 폭락에도 버틴 가격 등) / 없음 |
| 매물대 | · 1차 ○○,○○○~○○,○○○원 (형성 시기)<br>· 2차 ...<br>· 3차 ... |
| 안 사려는 구간 | ○○,○○○원 (번번이 막힌 가격) |
| 매수 타이밍 | · ○○원 돌파 후 선발대 연속 출현 시, 비중 작게 |
| 매도·손절 기준 | · 목표 ○○원 (다음 매물대) / 손절 ○○원 |
| 목표가 | ○○,○○○원 |

## 흐름 분석

1. {기간} 시장은 ○○하는데 종목은 ○○한다.

   ->{해석: 매수세/매도세/보유자가 ~하다는 것이다.}

2. {일자} 호재/급등/급락 ... 위꼬리/아래꼬리 남기며 ○○%로 마감했다.

   ->{해석}

(시간 순서로 계속)

## 거래량

- {대량 거래 구간과 가격대, 증감 추세, 해석}

## 사람 관점 질문

1. 최근 상승 때 매수한 사람들은 어떤 생각으로 샀을까? -> 
2. 보유자는 어떤 이유로 보유 중이고, 어떻게 대응할까? -> 
3. 이전 고점에서 물린 사람들은 본전에 오면? -> 
4. 지금 매도하는 사람은 누구일까? -> 
5. 나라면 언제 사고 언제 팔 것인가? -> 

## 결론 및 시나리오

- 현재 심리: 
- ○○원 돌파 시(작은 거래량이면 더 좋음): 
- 돌파 실패 시: ○○원(매도자 없는 가격)까지 하락 가능
- 확인할 조건: 장 후반 매수세 유지 / 다음날 시가 / 시장 방향

- 실제 흐름:
```
