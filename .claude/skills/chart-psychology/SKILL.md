# 차트 심리분석

사용자가 수년간 써온 분석법이다. 목표는 차트의 모든 움직임을 **"누가, 왜 사고 팔았는가"**로 번역하는 것.
해석 규칙은 [references/principles.md](references/principles.md), 보고서 양식은 [references/template.md](references/template.md),
실제 사례는 [references/examples.md](references/examples.md)를 참고한다.

## 입력 받기

1. **종목 차트** (필수): 캡처 이미지, 또는 일봉 OHLCV 데이터. 기간은 최소 1~2년 (장기 매물대 확인용).
2. **같은 기간 시장 지수 차트** (코스닥/코스피): 없으면 사용자에게 요청한다. 시장 비교 없이는 이 분석법이 성립하지 않는다.
   받을 수 없으면 기억하는 시장 흐름(예: 18년 10월 폭락, 20년 3월 코로나 폭락, 22년 하락장)을 쓰되 "시장 흐름은 추정"이라고 밝힌다.
3. **이벤트**: 호재/공시, 권리락·무상증자·배당락·감자 (차트 표시를 읽는다. 권리락 전후 가격은 수정주가인지 확인).
4. 사용자의 보유 여부·평단 (있으면 보유자 관점 질문에 활용).

차트 이미지에서 이동평균선 색은 키움 기본값 기준: 5(분홍/검정)·20(하늘)·60(빨강)·120(검정 얇은)·200/240(파랑/자주)·480(올리브). 범례를 먼저 읽고 확인한다.

## 분석 절차

### 1단계. 큰 흐름 (월·주봉 감각)
- 최고점·최저점, 장기 추세(저점을 낮추는지/높이는지), 긴 이평선(120·200) 위치.
- 시장 지수의 사이클(급등 고점 / 폭락 저점 / 횡보)과 종목 흐름을 겹쳐 본다.

### 2단계. 구간별 시장 대비 반응 (핵심)
시간 순서로 구간을 나누고, 각 구간마다 아래 4가지를 판정한다.
| 시장 | 종목 반응 | 해석 |
|---|---|---|
| 하락 | 크게 안 빠짐(버팀) | 매도할 사람이 없다 |
| 하락 | 같이/더 빠짐, 거래량 적음 | 매도세 증가가 아니라 매수세 위축 |
| 상승 | 못 따라감 | 매수세 관심 없음 / 비싸게 사려는 사람 없음 |
| 상승 | 빠르게 회복·신고가 | 기대감 있는 매수세 유입 |

"버티는데 상승도 못 한다" = 매수세가 강한 게 아니라 **보유자 자체가 없는 것**. (매수세가 강하면 시장 상승 때 따라 올라야 한다.)

### 3단계. 주요 캔들 해석
호재일·급등일·급락일·신고가일 등 눈에 띄는 날만 골라 일자별로 서술한다.
- 캔들 모양(시가 위치, 위꼬리/아래꼬리 길이, 마감 위치) → 선발/후발 매수·매도세 → 확신 유무.
- 다음날 반응으로 가설을 검증한다 ("그러고 보니 시장이 -2.8% 하락했다 → 매수세 위축이었다").

### 4단계. 거래량
- 평균 거래량 대비 증감, 대량 거래량이 나온 가격대(= 매물대 후보).
- 상승 중 거래량 감소 + 위꼬리 반복 → 추가 매수 없음, 보유자도 보유 의지 약화.
- 조정 중 평균 거래량 증가하며 하락 → 매수/매도 공방, 주포 이탈 가능성 의심.
- 매물대를 **작은 거래량으로 돌파** → 매도할 사람이 없어 작은 매수세로도 상승 가능.

### 5단계. 매물대·저점 확정
- 1차·2차·3차 매물대를 가격 범위와 형성 시기로 적는다 (예: `21,800~22,700원 (19년 6~7월)`).
- 저점: 시장 폭락에도 더 안 빠진 가격, 반복 지지 가격. 일봉 심리분석 후 확정. 없으면 "저점 없음"이라고 쓴다.
- "안 사려는 구간"(번번이 막히는 가격)을 따로 표시.

### 6단계. 사람 관점 질문에 답하기
분석 말미에 반드시 다음 질문을 스스로 묻고 답한다.
1. 최근 상승 때 매수한 사람들은 어떤 생각으로 샀을까?
2. 지금 보유자들은 어떤 이유로 보유하고 있을까? 2배 이상 올랐다면 어떻게 대응할까?
3. 이전 고점에서 물린 사람들은 본전 가격에 오면 어떻게 할까?
4. 지금 하락할 때 매도하는 사람은 어떤 사람들일까?
5. 나라면 언제 매수하고, 언제 매도(손절 포함)할 것인가?

### 7단계. 결론과 시나리오
- 현재 심리 요약 한두 문장.
- 시나리오: "○○원을 작은 거래량으로 돌파하면 → ..." / "돌파 실패 시 → ○○원(매도자 없는 가격)까지 하락 가능".
- 매수 시점 원칙 (사용자 자기반성에서 나온 규칙):
  - 매물대(안 사려는 구간) **돌파 후 선발대가 연속으로 나오는 시점**, 비중은 작게.
  - 장 초반 매수 금지 → **장 후반까지 매수세 유지 확인** 또는 **다음날 시가가 낮게 시작하지 않는지** 확인 후 매수.
  - 시장 변동성이 남아 있으면 차라리 **시장과 함께 하락했을 때**를 노린다.
  - 단타는 **20일 이평선** 기준 대응.
- 매도·손절 기준을 매수 전에 함께 정한다.

## 출력

- [references/template.md](references/template.md) 양식으로 작성하고, 요청 시 `분석/종목명_YYMMDD.md`로 저장한다.
- 사용자 문체: 서술형 "~한다. ~것이다." 해석은 `->` 로 이어 쓴다.
- 이미지에서 확실히 읽히지 않는 값은 `(추정)` 표시. 수치를 지어내지 않는다.
- 사용자가 과거 분석 복기를 원하면, 당시 판단과 이후 실제 흐름을 비교해 **자기반성** 항목을 채운다.
- 매수/매도를 단정적으로 권하지 않는다. 심리 판단과 조건부 시나리오까지가 역할이다.
